## 📖 Overview

Aldehyde is a pre-configured Linux bootc image based on [Bazzite-DX](). It combines the performant COSMIC desktop with tweaks, essential tools, and automation for a practical user enviroment. Whether you're coding, browsing, gaming, or managing servers, this image has you covered. 🌟

## ✨ Key Features

- **The COSMIC Desktop** 🌌: Pre-tweaked for productivity. Includes custom keyboard shortcuts for quick app switching, window management, and task automation. Comes with a curated set of stunning 4K wallpapers featuring abstract designs, nature scenes and astronomical moments

- **Auto CPUFreq** ⚡: Intelligent CPU frequency scaling for balancing performance and battery life. Automatically adjusts based on workload – perfect for laptops or desktops.

- **Kernel Arguments** 🛠️: Extensively optimized for performance dynamics with efficiency in mind
